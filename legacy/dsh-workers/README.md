# dsh-workers (compatibility notice)

This plugin is only a migration notice. The worker plugin was renamed to
[`agent-workers`](https://github.com/Cesar-M-Diaz/agent-workers).

If you intentionally want the notice plugin:

```text
/plugin install dsh-workers --marketplace Cesar-M-Diaz/agent-workers
```

Otherwise install `agent-workers@agent-workers`, move your settings, and remove
this plugin. It has no MCP server and cannot start workers.
